## 新しい回を追加する（運営メンバー向け）

1. [`_template/`](_template/) をコピーして、`YYYY-MM-DD_テーマ` の名前にする（例：`2026-11-20_時間インテリジェンス`）
2. 中の `README.md` を埋める
3. 上の一覧表の**先頭**に1行足す
4. push 前に [公開前チェックリスト](../docs/publishing-checklist.md) を確認する
