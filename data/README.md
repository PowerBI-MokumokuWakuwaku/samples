# data — わくわくマート サンプルデータ

勉強会で共通に使うサンプルデータです。**すべて架空のデータ**で、実在の企業・個人とは関係ありません。

**[wakuwaku_mart_sample.xlsx をダウンロード](https://github.com/PowerBI-MokumokuWakuwaku/samples/raw/main/data/wakuwaku_mart_sample.xlsx)**（約 4MB）

## どんなデータ？

食品・日用品・文具・家電を扱う架空の小売チェーン「わくわくマート」の、2024年1月〜2026年12月の3年分の売上データです。1つの Excel ブックに6つのシートがあります。

## 表のつながり

```
                 商品 ──(商品ID)──┐
                                  │
顧客 ──(顧客ID)── 売上明細 ───────┘
 │                   │
(都道府県)        (注文ID)
 │                   │
地域                返品

予算 ── 地方・カテゴリ・年月で 地域／商品／日付 とつなぐ
```

| つなぐ列 | 1 側 | 多 側 |
|---|---|---|
| 商品ID | 商品 | 売上明細 |
| 顧客ID | 顧客 | 売上明細 |
| 都道府県 | 地域 | 顧客 |
| 注文ID | （注文単位） | 売上明細・返品 |

- **売上明細** がファクト、**商品・顧客・地域** がディメンションの、スタースキーマの練習にちょうどよい形です
- **返品** は明細ではなく**注文ID 単位**です。売上明細と直接つなぐと多対多になるので、注文の表を作るか、DAX で扱う練習に使えます
- **予算** は「月 × 地方 × カテゴリ」と、売上明細より粗い粒度です。粒度の違う表を比べる（予実比較）練習に使えます
- 日付テーブルは入っていません。Power BI 側で作ってください

## シートと列

### 売上明細（65,704 行）

1 行 = 注文の明細 1 行。1 つの注文に明細は最大 5 行です。

| 列 | 内容 | 例 |
|---|---|---|
| 注文ID | 注文の番号 | ORD-2024-000001 |
| 明細番号 | 注文内の行番号（1〜5） | 1 |
| 注文日 | 2024-01-01 〜 2026-12-31 | 2024-01-01 |
| 出荷日 | 注文日以降 | 2024-01-01 |
| 配送方法 | 通常配送／お急ぎ便／当日配送／店頭受取 | 店頭受取 |
| 販売チャネル | 店舗／オンライン／法人営業 | 店舗 |
| 顧客ID | → 顧客 | C00769 |
| 商品ID | → 商品 | P0018 |
| 数量 | 1〜40 | 1 |
| 単価 | 円 | 1180 |
| 割引率 | 0〜0.4 | 0.1 |
| 売上金額 | 数量 × 単価 × (1 − 割引率)、円 | 1180 |
| 売上原価 | 円 | 730 |

## データを追加するときのルール（運営メンバー向け）

- 実データ（顧客・会社・個人のデータ）は置かない
- 社名・人名は架空のもの（例：「もくもく商事」「山田太郎」）を使う
- オープンデータを使うときは、出典（提供元、URL、取得日）とライセンスをこの README に書く
