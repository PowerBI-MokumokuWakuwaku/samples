# 公開前チェックリスト

push する前に確認します。

## データ

- [ ] 実データ（顧客・会社・個人のデータ）が入っていない
- [ ] オープンデータは出典とライセンスを [`data/README.md`](../data/README.md) に書いた

## Power BI ファイル

- [ ] `.pbix` の中のデータが架空 / オープンデータだけになっている（.pbix はデータを丸ごと含む）
- [ ] PBIP の `.pbi/cache.abf` と `.pbi/localSettings.json` がコミット対象に入っていない
- [ ] Power Query の接続先に社内サーバー名、SharePoint の URL、ローカルのユーザー名入りパス（`C:\Users\...`）が残っていない
- [ ] パラメーターや M コードに、API キー・パスワード・接続文字列が書かれていない
- [ ] テナント ID、ワークスペース ID、レポート ID が残っていない

## 資料

- [ ] スライドやスクリーンショットに、社内の画面・メール・名前が写り込んでいない
- [ ] PowerPoint のノートやコメントに、内部向けのメモが残っていない
- [ ] ファイルのプロパティ（作成者・会社名）を確認した
