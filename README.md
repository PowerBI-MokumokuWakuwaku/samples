# Power BI もくもく・わくわく会

Power BI もくもく・わくわく会で使うサンプル（PBIP / .pbix、DAX、Power Query、サンプルデータ、資料）の置き場です。

## フォルダ構成

| フォルダ | 中身 |
|---|---|
| [`sessions/`](sessions/) | 開催回ごとの資料・サンプル（`YYYY-MM-DD_テーマ` 形式） |
| [`samples/`](samples/) | 回をまたいで使う、テーマ別のサンプル |
| [`data/`](data/) | サンプルデータ（架空データ・オープンデータのみ） |
| [`docs/`](docs/) | 運用メモ（公開前チェックリストなど） |

## 使い方

- 1ファイルだけ欲しいとき：ファイルを開いて右上の **Download raw file** をクリック
- まとめて欲しいとき：このページ上部の **Code → Download ZIP**
- PBIP 形式のサンプルは、フォルダごとダウンロードして `.pbip` ファイルを Power BI Desktop で開いてください

## データについて

ここにあるデータは、すべて**架空のデータ**か**出典を明記したオープンデータ**です。実在の企業・個人のデータは含みません。
